Modul Tutorial Konfigurasi Mikrotik di VirtualBox

Assalamualaikum Wr. Wb.

Puji syukur kita panjatkan ke hadirat Allah SWT. Modul ini disusun sebagai panduan praktis konfigurasi Router Mikrotik di VirtualBox agar pembaca dapat memahami dasar jaringan secara sistematis.

Tujuan Pembelajaran

  • Memahami topologi jaringan sederhana
  • Instalasi RouterOS di VirtualBox
  • Mengonfigurasi Mikrotik untuk berbagi internet
  • Melakukan uji koneksi

Topologi Jaringan

Internet (ISP/Modem) → VirtualBox → Mikrotik RouterOS → Client

  • Ether1 = WAN (Internet)
  • Ether2–5 = LAN
  • Bridge LAN menyatukan semua port LAN

1. Reset Router

Agar konfigurasi bersih, lakukan reset router terlebih dahulu melalui terminal.

/system reset-configuration

2. Ganti Password Admin

Supaya router lebih aman, segera ubah password default.

/password

3. Membuat Bridge LAN

Bridge digunakan agar ether2–5 menjadi satu jaringan LAN.

/interface bridge add name=bridge-LAN /interface bridge port add bridge=bridge-LAN interface=ether2 /interface bridge port add bridge=bridge-LAN interface=ether3 /interface bridge port add bridge=bridge-LAN interface=ether4 /interface bridge port add bridge=bridge-LAN interface=ether5

4. IP LAN & DHCP Server

/ip address add address=192.168.10.1/24 interface=bridge-LAN /ip pool add name=pool-LAN ranges=192.168.10.100-192.168.10.200 /ip dhcp-server add name=dhcp-LAN interface=bridge-LAN address-pool=pool-LAN /ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1

5. Mengatur WAN (DHCP Client)

/ip dhcp-client add interface=ether1 disabled=no

6. NAT (Agar Klien Bisa Internet)

/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

7. Uji Koneksi

/ping 8.8.8.8

Jika reply berhasil, maka router dan klien sudah terhubung ke internet.

Tips Tambahan

/ip service disable telnet /ip service disable ftp /ip service disable www
