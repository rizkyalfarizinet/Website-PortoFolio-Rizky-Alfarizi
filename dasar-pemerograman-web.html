Dasar HTML

Pemahaman Struktur & Fondasi Website

1. Pengertian HTML

HTML (HyperText Markup Language) adalah bahasa dasar untuk membuat struktur halaman web. HTML digunakan untuk menyusun konten seperti teks, gambar, dan link agar bisa ditampilkan di browser.

2. Struktur Dasar HTML

<!DOCTYPE html>
<html>
<head>
<title>Judul</title>
</head>
<body>
Konten Website
</body>
</html>

Struktur ini adalah kerangka utama dalam setiap halaman web.

3. Elemen HTML

  • Heading (h1 - h6)
  • Paragraf (p)
  • Link (a)
  • Gambar (img)
<h1>Judul</h1>
<p>Paragraf</p>
<a href="#">Link</a>

4. Atribut HTML

Atribut memberikan informasi tambahan pada elemen HTML.

<a href="https://google.com">Klik disini</a>

5. Elemen Penting HTML

Section & Div

<section>Konten</section>
<div>Konten</div>

List

<ul>
  <li>Item</li>
</ul>

Strong & Em

<strong>Penting</strong>
<em>Penekanan</em>

6. Media HTML

Gambar

<img src="gambar.jpg" alt="deskripsi">

Audio

<audio src="audio.mp3" controls></audio>

Video

<video src="video.mp4" controls></video>

7. Link & Navigasi

<a href="halaman.html">Pindah Halaman</a>

Link digunakan untuk berpindah antar halaman dalam website.

8. Path (Lokasi File)

Relative Path:

./images11/gambar.png

Absolute Path:

https://example.com/image.png

9. SEO & Meta Tag

<meta name="description" content="Belajar HTML">

Meta tag membantu mesin pencari memahami isi website.

10. Multimedia & Embed

<iframe src="https://example.com"></iframe>

Digunakan untuk menampilkan konten dari website lain seperti video YouTube.
